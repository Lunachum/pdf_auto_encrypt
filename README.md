# pdf_auto_encrypt

監視フォルダに PDF ファイルが保存されたとき、自動的にパスワード付き (AES-256) のコピーを出力先フォルダに作るツールです。

家業 (ステッカー制作) で、お客様に送る PDF の保護を毎回手作業でしていた手間をなくすために作りました。

## 主な機能

- フォルダを監視し、PDF の作成・保存・移動を検知して自動で保護 (watchdog)
- AES-256 で暗号化。閲覧用のユーザーパスワードと、権限設定用のオーナーパスワードを設定できる (pypdf)
- 印刷・編集・コピーなどの権限を `USER_PERMISSIONS` で設定できる (デフォルトは閲覧のみ)
- 保存中のファイルは処理せず、保存が終わって `SETTLE_SECONDS` 秒 (デフォルト 2 秒) 変化がなくなってから 1 回だけ処理する
- 出力先に同じ名前のファイルがある場合は `出力先\.backups` にバックアップする
- 出力先が監視フォルダと同じか、監視フォルダの中にある場合は起動しない (無限ループ防止)

## 必要なもの

- Python 3.11 以上

## インストール

### venv 環境を作る (推奨)

Windows の場合:

```
python -m venv .venv
.venv\Scripts\activate
```

### 必要なパッケージのインストール

```
python -m pip install -r requirements.txt
```

## 使い方

```
python pdf_auto_encrypt.py <元のPDFが保存されるフォルダ> <パスワード付きPDFの出力先>
```

`<` と `>` は説明用の記号なので、入力しません。

起動すると、パスワードを入力する画面になります (入力した文字は表示されません)。

```
オーナーパスワード:
確認のため、もう一度入力してください:
ユーザーパスワード (閲覧用。設定しない場合は空のまま Enter):
```

- **オーナーパスワード**: 権限設定用のパスワードです。オーナーパスワードを知らない人は PDF の編集・印刷などができなくなります。
  ただし、PDF の仕様上、権限の制限は完全な保護ではありません。対応していないソフトや pypdf のようなツールで制限を外される可能性があります。
- **ユーザーパスワード**: PDF を開くためのパスワードです (設定しなくてもよいです)。

例:

```
python pdf_auto_encrypt.py C:\PDF作業用 C:\共有用
```

相対パスも指定できます:

```
python pdf_auto_encrypt.py PDF作業用 PDF共有用
```

### 環境変数でパスワードを渡す場合

自動起動などで画面から入力できない場合は、環境変数でパスワードを渡せます。
環境変数 `PDF_OWNER_PASSWORD` が設定されていると、画面からの入力は行いません。

| 環境変数 | 内容 |
| --- | --- |
| `PDF_OWNER_PASSWORD` | オーナーパスワード |
| `PDF_USER_PASSWORD` | ユーザーパスワード (設定しなければ、パスワードなしで開ける PDF になります) |

```
set PDF_OWNER_PASSWORD=ここにパスワード
python pdf_auto_encrypt.py C:\PDF作業用 C:\共有用
```

> 以前のバージョンではパスワードをコマンド引数で渡していましたが、コマンド引数はタスクマネージャーやコマンド履歴から他の人にも見えてしまうため、使えなくしました。
> 環境変数を bat ファイルに書く場合も、そのファイル自体を他の人が読めない場所に置き、Git にはコミットしないでください。

## 設定

`pdf_auto_encrypt.py` の先頭にある `=== 設定 ===` の部分で変更できます。主な設定:

| 設定 | デフォルト | 内容 |
| --- | --- | --- |
| `USER_PERMISSIONS` | `0` | ユーザーに許可する操作。`0` で閲覧のみ。例: `UserAccessPermissions.PRINT` で印刷を許可 |
| `SETTLE_SECONDS` | `2.0` | 保存が終わったと判断するまでの秒数。ネットワークフォルダなどで途中のファイルが処理される場合は増やす |
| `BACKUP_ENABLED` | `True` | 出力先の同名ファイルをバックアップするか |
| `HOOK_ON_CREATED` / `HOOK_ON_MODIFIED` / `HOOK_ON_MOVED` | `True` | ファイルの作成・変更・移動のときに処理するか |
| `SAFE_DIRECTORY` | `True` | 出力先が監視フォルダの中にある場合に起動しないか |

## 注意

「元のPDFが保存されるフォルダ」の中に「パスワード付きPDFの出力先」を作らないでください。
安全のため、その場合は起動時にエラーで終了します。
